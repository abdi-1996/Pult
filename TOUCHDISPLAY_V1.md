# TouchDisplay v1

Первая Android + Windows версия сенсорного удалённого дисплея.

## Что уже работает

- Android-планшет показывает основной экран Windows на весь экран.
- Одно касание и multi-touch передаются в Windows через `InjectTouchInput`, а не как движение мыши.
- Подключение по обычной LAN/Wi‑Fi сети.
- Подключение вне дома через Tailscale: в Android укажите `100.x.x.x` адрес ПК или MagicDNS-имя.
- PIN из 6 цифр для подключения.
- Windows Host показывает LAN/Tailscale адрес и запускается одним EXE.
- GitHub Actions собирает APK и self-contained EXE.

## Установка

1. На Windows запустите `TouchDisplayHost-v1.exe`.
2. Если Windows Firewall спросит доступ, разрешите для частной сети. Для Tailscale также разрешите приложению принимать соединение.
3. На Android установите `TouchDisplay-v1.apk`.
4. В приложении Android введите IP ПК, порт `59432` и PIN, который показан в Host.
5. Для доступа вне дома запустите Tailscale на ПК и Android и используйте Tailscale IP/MagicDNS.

## Ограничения v1

- Сейчас зеркалируется основной монитор Windows. Виртуальный второй монитор (Extend) будет отдельным драйверным этапом.
- Поток v1 использует JPEG до 1600 px и ориентировочно 20 FPS. Следующая версия будет переходить на аппаратный H.265/AV1 для 60 FPS и меньшей задержки.
- USB Display, Pen API, Android-клавиатура и автоматическое обнаружение ПК запланированы на следующие версии.

## Сетевой протокол v1

TCP порт `59432`. Канал рассчитан на LAN либо защищённую Tailscale-сеть. Не рекомендуется открывать порт напрямую в интернет.
